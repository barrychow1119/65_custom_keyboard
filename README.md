# Custom 65% Keyboard

Two-board design: passive key matrix + RP2040 controller.

## keyboard-main (key board)
- 306 × 97 mm, 2 layers, 1.6 mm, HASL lead-free
- 68 keys, Kailh MX hotswap, SOD-123F diodes, 4 stabilisers
- 16 cols × 5 rows → 30-pin 0.5 mm FFC
- Traces 0.127 mm, vias 0.6/0.3 mm
- Components on F.Cu (board mounts flipped in case)
